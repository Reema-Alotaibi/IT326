#  Heart Disease Prediction Using Machine Learning

##  Project Overview

This project was developed as a **group project for IT326** and focuses on applying Machine Learning techniques to the prediction and analysis of heart disease.

Using a real-world heart disease dataset, we explored important health-related factors such as **age, blood pressure, cholesterol levels, and exercise-related symptoms** to identify patterns associated with heart disease risk.

The project demonstrates how Machine Learning can be applied to a real-world healthcare problem to support **early risk identification and data-driven decision-making**.

---

##  Project Objectives

The main objectives of this project are to:

* Analyze a real-world heart disease dataset.
* Identify important factors associated with heart disease.
* Build Machine Learning models for **classification**.
* Apply **clustering techniques** to discover groups of individuals with similar health profiles.
* Evaluate the performance of the developed models.
* Extract meaningful patterns and insights from the dataset.

---

##  Machine Learning Techniques

The project explores two main Machine Learning approaches:

### Classification

Classification techniques are used to predict whether an individual is at risk of heart disease based on the available health-related features.

### Clustering

Clustering techniques are used to group individuals with similar health characteristics, helping identify patterns and potential risk profiles within the dataset.

---

##  Dataset

The dataset contains various health-related attributes that can be used to analyze heart disease risk, including factors such as:

* Age
* Blood pressure
* Cholesterol
* Exercise-related symptoms
* Other relevant clinical and demographic features

The dataset is included in the `Dataset` folder.

##  Project Motivation

Heart disease is one of the major health challenges worldwide. Early identification of individuals who may be at higher risk can support timely intervention and better health management.

This project provided an opportunity to apply Machine Learning concepts to a meaningful real-world healthcare problem while gaining practical experience in **data preprocessing, exploratory data analysis, classification, clustering, and model evaluation**.
